# MediExtract AI

## Project Setup

### Project Name
MediExtract AI: Intelligent Clinical Note Classification & Medical Information Extraction using Medical NLP

### Objective
To build an AI-powered web application that automatically extracts medical information from clinical notes, classifies them into medical departments, predicts ICD-10 codes, and stores the results for future reference.

### Technology Stack

Frontend:
- React.js

Backend:
- FastAPI

Machine Learning:
- Python
- spaCy
- Transformers
- BioBERT

Database:
- MongoDB

Version Control:
- Git & GitHub

Deployment:
- Vercel
- Render
- MongoDB Atlas
